        Создаю структуру с объектом и массивом , которая описывает пользователя и его друзей.
1. Создаю объект user , в котором такие свойства:
- name - строчка ( имя пользователя)
- age - число (возраст)
- isOnline - булевое значение (онлайн ли)
- friends - массив с 3 именами друзей (рядки)
- settings - вложенный объект с полями:
  - theme - ряд ("light" / "dark")
  - notifications - булевое значение (включено уведомление)

2. Создаю отдельную переменную firstFriendName , которая получает значение первого друга user.friends.
3. Создаю отдельную переменную notificationsEnable , которая получает значение user.settings.notifications.

     
    Выведу в консоль:
- Имя пользователя,
- Количество друзей (не через метод, используя .length),
- Имя первого друга,
- Какая тема включена,
- Включены ли уведомления.
